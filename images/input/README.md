# Input images

The correction bundle contains `original-road-image.png`, a crop from the user's MATLAB screenshot. It is 256 × 343 pixels because the submitted source was a screenshot of a MATLAB figure rather than the standalone input photograph.

For best clarity and future experiments, add the original full-resolution road photograph as `road.png` in the project root (the current MATLAB script's expected input) and optionally keep a copy here for reference.

Use images you are allowed to share and retain source/attribution details where applicable.
