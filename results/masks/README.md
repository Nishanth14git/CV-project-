# Colour segmentation results

The following supplied MATLAB screenshots are stored in this folder:

- `rgb-red-mask.jpg` — RGB red threshold mask.
- `hsv-red-mask.jpg` — HSV red threshold mask.

## Comparison

For the demonstrated road image, the author found that RGB provided a clearer representation of the red sign border and removed more unwanted white noise than the HSV mask. The masks also show a small residual foreground speck. The RGB choice is specific to this image and threshold configuration.
