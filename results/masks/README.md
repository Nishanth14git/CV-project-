# Colour segmentation results

Upload these corrected PNG screenshots from the image-corrections bundle:

- `rgb-red-mask.png` — RGB red threshold mask.
- `hsv-red-mask.png` — HSV red threshold mask.

For the demonstrated road image and selected thresholds, the author found that RGB produced a clearer representation of the red sign border and fewer unwanted white regions than HSV. This comparison is specific to that image and threshold configuration.
